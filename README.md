# 💬 AI Chatbot – Built with IBM Watsonx Studio  
This project is an AI-driven web based chatbot developed as part of my internship at **Edunet Foundation** in collaboration with **AICTE and IBM**. The chatbot leverages **IBM Watsonx Assistant** to provide dynamic, intelligent responses to user queries.

### 📌 **Project Overview**  
The chatbot was developed to provide seamless interaction with users by simulating human-like conversations. This project focuses on enhancing user experience and automating responses to frequently asked questions.  

**Key Features:**  
- Natural Language Processing (NLP) for accurate query handling  
- Deployed via **IBM Watsonx Assistant**  
- Customizable intents and responses  
- Scalable and adaptable for various industries  

---

### ⚙️ **Technologies Used**  
- **IBM Watsonx Studio**  
- **Watson Assistant**  
- **AI/ML** for intent recognition and response generation
